# Local Development Setup

## Quick Start - Local Frontend + Production Backend

Your React app is already configured to connect to your production AWS resources for local development.

### 1. Start the Development Server

```bash
cd react-frontend
npm run dev
```

**Access at:** http://localhost:5173/

### 2. How It Works

The app will:
1. **Try to load config from `/config.json`** (won't exist locally)
2. **Fallback to environment variables** from `.env.local`:
   ```
   VITE_USER_POOL_ID=us-east-1_6QZ8ANScT
   VITE_USER_POOL_CLIENT_ID=5gf3gocpg5eu3c01ipeee4tib2
   VITE_API_ENDPOINT=https://c9wu2knteb.execute-api.us-east-1.amazonaws.com/prod
   ```

3. **Connect to your live AWS resources:**
   - Cognito User Pool for authentication
   - API Gateway for backend calls
   - DynamoDB for data storage

### 3. Test Bot Creation (Previously Broken)

**Expected Result:** ✅ Bot created successfully (no more 401 errors)

### 4. Authentication Flow

The fixed authentication now:
- Gets JWT token from AWS Cognito
- Passes it correctly in `Authorization: Bearer <token>` header
- Includes proper `X-User-ID` header
- Communicates directly with your backend API

### 5. Why This Works Now

**Previous NextJS Issues:**
- API routes returned HTML instead of JSON
- Static export couldn't handle authentication
- Complex routing broke navigation

**New React Solution:**
- Direct backend API communication
- Proper JWT token handling
- Client-side routing with React Router
- Simple static file serving

### 6. Development vs Production

**Local Development:**
- Uses `.env.local` environment variables
- Runs on http://localhost:5173/
- Hot reload with Vite

**Production Deployment:**
- Uses `config.json` generated by CDK
- Runs on CloudFront distribution
- Static files served from S3

Both use the **same authentication flow** and **same backend APIs**.

## Troubleshooting

**Can't sign in?**
- Check your Cognito User Pool settings
- Verify the User Pool ID and Client ID are correct

**Still getting 401 errors?**
- Check browser dev tools → Network tab
- Verify Authorization header is being sent
- Check if JWT token is valid

**Config not loading?**
- Verify `.env.local` file exists and has correct values
- Check browser console for errors
